4. **`linear/DESIGN.md`**: Linear's dark UI precision — Vibrant micro-gradients, tight typography, glowing active states, and keyboard-first telemetry.
5. **`vercel/DESIGN.md`**: Vercel's stark monochrome precision — High-contrast black and white canvas with Geist typography and ultra-sharp edges.
