RS Writing Instruments is a luxury web application for handcrafted ebonite feeds, bespoke fountain pen mechanisms, and fountain pen artisan craftsmanship based in India.

## 🌟 Key Features

- **Design System (`DESIGN.md`)**: Built adhering to the [VoltAgent/awesome-design-md](https://github.com/VoltAgent/awesome-design-md) standard.
- **Bespoke Fountain Pen Catalog**: High-definition discovery grid for hand-turned ebonite fountain pens.
- **Standalone Ebonite Feeds Line Sheet**: Detailed specifications for Parker, Shaffer, single, double, and triple capillary ink channel feeds.
- **PDF Specification Line Sheet Modal**: Instant B2B catalog view and print layout.
- **WhatsApp CRO Integration**: Direct-to-artisan ordering via WhatsApp.
- **Patriotic Independence Day Offer Banner**: Festive CRO banner with Indian flag tricolor styling.
- **Smooth Momentum Scrolling**: Powered by Lenis & GSAP.

## 📁 Design System Presets

The project includes machine-readable `DESIGN.md` files:
- `DESIGN.md`: Primary root design specification.
- `design-md/rs-luxury/DESIGN.md`: High-craft luxury atelier design tokens.
- `design-md/README.md`: Preset library documentation.

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

## 🛠 Tech Stack

- **Framework**: Next.js 16 (App Router with Turbopack)
- **UI & Logic**: React 19, TypeScript 5, TailwindCSS 4
- **Animations**: GSAP, Lenis Smooth Scroll
- **Icons**: React Icons (FaWhatsapp, FaFeather, HiSearch, HiPrinter)
